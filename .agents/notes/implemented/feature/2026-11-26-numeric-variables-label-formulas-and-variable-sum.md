# Agent Note: 数字变量、文字公式与变量筛选求和

Status: implemented

## Problem

计算笔记本不允许数字开头变量，带空格说明文字后的裸公式会被整行误解析，`sum()` 也只能汇总显式列出的普通数字。用户需要按编号命名变量、自然书写“说明：公式”，并按变量名前后缀汇总当前行之前的变量。

## Decision

- 允许数字开头且后续含中文、字母或下划线的变量；纯数字名称及与“数字 + 已注册单位”冲突的名称仍禁止。
- 数字变量只在当前块内先定义后引用，引用时由已定义变量表消除数字与单位之间的词法歧义。
- 支持 `说明：公式` 和 `说明: formula`，说明文字可含空格；每行只尝试第一个非时间冒号，保留 `{{公式}}`。
- 扩展 `sum("前缀*")`、`sum("*后缀")` 和 `sum("*")`，只汇总此前成功定义的变量，同名重定义取最新值一次，空匹配返回零，类型运算沿用现有规则。

## Alternatives considered

允许数字变量直接覆盖单位写法最省事，但会让 `1m` 的含义随定义变化，因此拒绝。另设 `sumPrefix()`、`sumSuffix()` 能避免重载 `sum()`，但会增加函数数量，因此采用单一首尾通配符语法。只允许 `{{公式}}` 不会产生冒号识别问题，但无法改善自然书写体验。

## Consequences

用户可按编号命名并自然书写说明公式，变量汇总无需逐项列名。数字变量依赖当前块已定义名称，未定义的“数字 + 单位”仍按单位解析；纯数字和单位冲突名称需要用户改名。`sum("*")` 会包含此前汇总变量，精确业务汇总应使用前后缀。
