# 等号计算 (Equals Calc)

思源笔记插件：在编辑器里输入以等号结尾的算式，**按回车**自动把结果补在等号后面。

## 安装

本增强分支的安装包发布在 [ljq29/plugin-calc Releases](https://github.com/ljq29/plugin-calc/releases/latest)：

1. 下载 `plugin-calc.zip` 并解压到思源工作空间的 `data/plugins/`。
2. 确认最终路径为 `<思源工作空间>/data/plugins/plugin-calc/plugin.json`。
3. 重新加载思源，在「设置 → 集市 → 已下载」中启用「等号计算」。

官方 Docker 容器内的工作区通常是 `/workspace`，因此插件路径为 `/workspace/data/plugins/plugin-calc/`；自定义 `--workspace` 或卷映射时以实际工作区为准。同一个 Docker 实例只需在服务器工作空间安装一次，访问它的浏览器无需分别复制插件；其他独立工作空间仍需分别安装。

官方集市已经收录 `pisceswb/plugin-calc`。本分支的增强功能通过上游 PR 回馈，合并并由原作者发布后，可直接在集市中更新；不要再向 Bazaar 添加重复的 `ljq29/plugin-calc` 条目。

## 功能

| 输入 | 按回车后 |
| --- | --- |
| `12*5=` | `12*5=60` |
| `测试12*5=` | `测试12*5=60` |
| `12×5=` | `12×5=60` |
| `12×5=60*3=` | `12×5=60*3=180` |

只有「光标前、且以等号结尾」的算式会被结算，行首的中文、单位等文字都会原样保留。

## 计算笔记本

需要思源 **3.8.10 或更高版本**。在编辑器中输入 `/计算`（也可用 `/calc` 筛选），插入一个独立的计算块。停止输入约 300 毫秒后自动保存。

```text
单价=68
数量=2
运费=10

商品金额：单价*数量
含运费总价：{{单价*数量+运费}}
单价*数量*0.8
```

预览结果：

```text
单价 = 68
数量 = 2
运费 = 10

商品金额：136 (单价*数量)
含运费总价：146 (单价*数量+运费)
108.8 (单价*数量*0.8)
```

- `变量名=公式` 定义变量，支持中文和数字开头的变量名；后面的内容可以引用前面已定义的变量
- 变量仅在当前计算块内有效；修改变量后，引用它的结果会自动重算
- 独立公式行直接显示为 `结果 (计算公式)`；普通文字与空行原样保留
- `说明文字：公式` 或 `说明文字: 公式` 可以直接计算，说明文字允许包含空格，例如 `A B C：AA+BB+CC`
- 普通文字中用 `{{公式}}` 嵌入结果，一行可放多个公式；未定义变量、除零、空公式和未闭合标记会显示错误
- 点击「隐藏公式」可只保留结果，再次点击可恢复公式
- 只把原始模板保存到自定义块，计算结果由插件实时生成；停用或卸载插件后仍可读取原文

### 数字开头变量与文字公式

变量可以以数字开头，但数字后必须还有中文、字母或下划线：

```text
1号=10
2号=20
2026收入=5000
编号合计：1号+2号
明年收入：2026收入*2
```

纯数字不能作为变量名。为避免同一个写法产生两种含义，`1m`、`2h`、`5kg` 等与“数字 + 已注册单位”重名的变量也会被拒绝；单位计算保持原样。变量名不能包含空格或运算符，并且仍然遵循先定义、后引用。

带说明的公式支持两种写法：

```text
AA=5
BB=7
CC=8
A B C ： AA + BB + CC
另一结果：{{AA*BB}}
```

第一种是冒号后的裸公式，第二种适合在一句话中嵌入一个或多个结果。普通文字、网址和时间中的冒号不会被误当作公式分隔符。

### 按变量名前后缀求和

除了 `sum(1,2,3)` 和 `sum(AA,BB)`，还可以用一个首尾通配符筛选当前行之前的变量：

```text
支出_餐饮=30
支出_交通=20
收入_餐饮=100

支出合计=sum("支出_*")
餐饮相关=sum("*_餐饮")
空匹配=sum("不存在_*")
```

结果分别为 `50`、`130` 和 `0`。`sum("*")` 汇总此前所有变量。

- 只统计当前行之前成功定义的变量，不统计普通公式行结果，也不引用后面的定义
- 同名变量重新定义时只计算最新值一次；汇总变量本身也是变量，之后的 `sum("*")` 会把它计入
- 匹配区分大小写；只支持 `前缀*`、`*后缀` 和 `*`，不支持中间或多个通配符
- 普通数字、时长和兼容单位可直接汇总，不同货币或不兼容类型会显示错误
- 此能力归入「分组汇总」功能开关，关闭后筛选求和也会停用

### 三种视图

块右上角提供「上下」「左右」「逐行」三个按钮。**默认使用左右视图**，左侧编辑原文、右侧显示结果；「上下」保留原文在上、结果在下的布局。

视图选择写入当前块的 `custom-plugin-calc-view` 属性，每个块分别记忆，刷新、重新打开和文档同步后仍会保留。

「逐行」是所见即所得模式：

- 未点击时全部显示结果，点击某一行后在原位置编辑该行的原文
- 修改当前行时，其他行的引用结果实时更新
- `Enter` 拆分行，行首 `Backspace` 与行尾 `Delete` 可合并相邻行
- `↑` / `↓` 切换编辑行，`Esc` 退出当前行编辑
- 自动保存后继续编辑时，会保留当前行、焦点和光标位置

### 一键追加学习示例

块右上角的「示例」按钮会在**当前计算块末尾**追加一套可以直接运行的学习模板，包含基础计算、数字开头变量、文字公式、前后缀求和、时间、日期、单位、自定义单位、时区和分组汇总。

- 保留已有内容，只追加，不覆盖
- 示例变量统一使用“示例”前缀，避免改变原有公式
- 示例自定义单位也只使用“示例打、示例盒、示例个”，避免重名
- 点击后立即显示计算结果，并通过现有自动保存逻辑写入当前块
- 重复点击不会重复追加；插件会定位到已有的 `【plugin-calc 学习示例】` 标记
- 左右、上下、逐行三种视图均可使用，不会改变当前视图
- 货币部分只提供操作提示，需要在插件设置中配置汇率后再计算，离线打开示例也不会因此报错

建议第一次使用时先插入 `/计算`，点击「示例」，然后直接修改示例里的时间、金额和单位，观察右侧或逐行预览的变化。

### 自动重算、手动计算与中文输入

「计算笔记本自动重算」类似 Excel 的自动计算开关，默认开启：

- 开启时，编辑后约 150ms 更新预览；自动保存仍约 300ms 执行
- 关闭时，打开计算块会计算一次，之后编辑只保存原文并保留旧预览，同时显示“结果未更新”
- 点击右上角「立即计算」可随时用当前原文刷新结果
- 重新开启自动重算或修改功能开关时，会立即刷新打开的计算块
- 自动保存始终有效，关闭自动重算不会丢失原文
- 手动模式下，在线汇率不会在后台自动改变预览

中文输入法组词期间暂停整块计算和自动保存，组词结束后恢复。因此输入“明天”等词语时，拼音中间态不会反复触发公式解析。

预览按顺序一次计算全部变量，后续公式直接引用已算出的值；普通预览只更新发生变化的行，不再为每行重复解析所有定义。

## 时间、日期与时区

无需给变量声明类型，插件会根据输入自动区分数字、时刻、时长、日期、日期时间、带时区时间、单位量和金额。

```text
开始时间=08:30
耗时=90min
结束时间：{{开始时间+耗时}}

日期=date("2026-11-26")
一周后：{{dateAdd(日期,1,"week")}}
相差天数：{{dateBetween(日期,date("2026-12-03"),"days")}}
中文日期：{{formatDate(日期,"YYYY年M月D日")}}
```

支持的主要写法：

- 时刻与时长：`08:30+90min` → `10:00`；`23:50+20min` → `00:10（次日）`
- 时间差：`17:20-08:30` → `8h50min`
- 时长组合：`1h30min to min` → `90min`
- 日期构造：`date("2026-11-26")`、`datetime("2026-11-26 08:30")`
- 日期函数：`dateAdd`、`dateSubtract`、`dateBetween`、`formatDate`、`today`、`now`
- 日期加减：`date("2026-11-26")+7d` → `2026-12-03`
- 工作日：`workdays(start,end)` 计算含起止日期的工作日；`addWorkdays(date,n)` 增加工作日
- 部件提取：`year`、`month`、`day`、`hour`、`minute`

### 日期函数速查

| 函数 | 用途 | 示例 |
| --- | --- | --- |
| `date(text)` | 构造纯日期 | `date("2026-11-26")` |
| `datetime(text)` | 构造不带时区的日期时间 | `datetime("2026-11-26 08:30")` |
| `zoned(text,zone)` | 构造带时区的日期时间 | `zoned("2026-11-26 15:00","Asia/Shanghai")` |
| `inZone(value,zone)` | 同一时刻转换到其他时区 | `inZone(会议,"Asia/Tokyo")` |
| `dateAdd(value,n,unit)` | 日历日期加减 | `dateAdd(日期,2,"months")` |
| `dateSubtract(value,n,unit)` | 日历日期回退 | `dateSubtract(日期,5,"days")` |
| `dateBetween(start,end,unit)` | 两个日期之间的差值 | `dateBetween(开始,结束,"days")` |
| `formatDate(value,format)` | 自定义显示格式 | `formatDate(日期,"YYYY年M月D日")` |
| `workdays(start,end)` | 含起止日期的工作日数 | `workdays(开始,结束)` |
| `addWorkdays(date,n)` | 增加若干工作日 | `addWorkdays(日期,5)` |
| `today()` / `now()` | 当前日期 / 当前带时区时间 | 重开文档后可能变化 |

日期单位支持 `years`、`months`、`weeks`、`days`、`hours`、`minutes`、`seconds` 及对应单数形式。`hours` 及以下单位需要 `datetime()` 或 `zoned()`，纯 `date()` 不能加减小时。

月份和年份按日历计算：`dateAdd(date("2026-01-31"),1,"months")` 得到 `2026-02-28`。固定时长与日历月年分开，不把一个月固定当成 30 天。

时区使用 IANA 名称，并且必须提供完整日期：

```text
会议=zoned("2026-11-26 15:00","Asia/Shanghai")
东京时间：{{inZone(会议,"Asia/Tokyo")}}
```

结果为 `2026-11-26 16:00:00+09:00[Asia/Tokyo]`。夏令时导致本地时间不存在或重复时会报错，不会静默选择。

## 单位、复合单位与自定义单位

```text
5km to m=              → 5000m
1m+20cm=               → 1.2m
2inch to cm=           → 5.08cm
32degF to degC=        → 0degC
1GiB to MiB=           → 1024MiB
100km/2h=              → 50km/h
50km/h*2h=             → 100km
60kg/m^2=              → 60kg/m^2
```

- 支持时间、长度、重量、面积、体积、数据量、温度、角度及中文常用别名
- 加减要求量纲一致；乘除会合并量纲并约分单位
- 温度包含零点偏移，不能简单当作比例单位
- `GB/MB` 按十进制，`GiB/MiB` 按二进制
- `2m^2` 是 2 平方米，`(2m)^2` 是 4 平方米
- 可用 `unit(2,"m")` 显式构造单位量
- 裸 `mi`、`m`、`h` 等名字不会自动变成 1 个单位；单位只在数字后、复合单位、转换目标或 `unit()` 中识别，因此 `mi` 和“明天”可正常作为文字，而 `5mi` 仍表示 5 英里

### 常用单位速查

| 类别 | 可用写法举例 |
| --- | --- |
| 时间 | `s`、`sec`、`min`、`h`、`d`、`week`、`秒`、`分钟`、`小时`、`天`、`周` |
| 长度 | `mm`、`cm`、`m`、`km`、`inch`、`ft`、`yd`、`mi`、`nmi`、`米`、`厘米`、`公里`、`英寸`、`英里` |
| 重量 | `mg`、`g`、`kg`、`tonne`、`lb`、`oz`、`斤`、`两`、`磅`、`盎司` |
| 面积 | `m^2`、`cm^2`、`km^2`、`hectare`、`ha`、`亩`、`平方米`、`公顷` |
| 体积 | `m^3`、`L`、`mL`、`升`、`毫升` |
| 数据量 | `bit`、`B`、`KB`、`MB`、`GB`、`TB`、`KiB`、`MiB`、`GiB`、`TiB` |
| 温度 | `K`、`degC`、`degF`、`℃`、`℉`、`celsius`、`fahrenheit` |
| 角度 | `rad`、`deg`、`°`、`弧度`、`度` |

长度、重量、面积等还支持相应的英文全称。`min` 是分钟、`m` 是米；数据单位中的 `b` 大小写和 `i` 是否有意义，例如 `MB` 与 `MiB` 不同。

计算块内可声明自定义单位，作用域仅限当前块：

```text
unit 打 = 12 个
unit 盒 = 6 打
两盒数量：{{2盒 to 个}}
```

结果为 `144个`。后面的定义可以引用前面的定义，重复定义会报错。

## 上一结果与分组汇总

```text
午餐：{{35}}
交通：{{12}}
咖啡：{{18}}
上一项：{{prev}}
合计：{{total}}
平均：{{average}}
```

- `prev` 是之前最近的计算结果，跳过普通文字和空行
- `total`、`average` 汇总当前空行分组内、当前行之前的独立公式与行内公式
- 变量定义行不参与汇总，避免重复计算
- 同量纲单位可汇总，例如 `5km` 与 `500m` 合计为 `5.5km`
- 不兼容的单位、不同币种或时间点混算会显示错误

## 货币换算

```text
费用=100USD
人民币：{{费用 to CNY}}
```

- 同币种可以直接加减；不同币种必须先用 `to` 转换
- 支持 `25USD/h*14h` → `350USD` 这类金额复合单位
- 设置里可填写手工汇率，例如 `{"USD/CNY":7.2}`，优先于在线汇率
- 在线参考汇率来自 [Frankfurter](https://frankfurter.dev/)，自动缓存并在设置中显示来源与日期；它不是实时交易报价
- 网络不可用时仍可使用缓存或手工汇率；没有任何可用汇率时会明确报错

## 运算规则与结果保存

- 类型由输入自动推断，不需要给变量声明 `time`、`date` 等类型
- 时间点可以加减排时长，两个时间点相减得到时长；两个时间点不能相加
- 单位加减必须量纲一致，`1m+20cm` 合法，`1m+1kg` 会显示错误
- 单位乘除可以构造复合量，单位相同的部分会自动约分
- 不同货币不能直接相加，必须先转换；固定单位换算不需要网络
- 原始模板始终保留在自定义块中，结果只负责预览，不会把计算结果写回公式
- `today()`、`now()` 和在线汇率具有动态性；需要可复现的账目时，请写固定日期、历史日期或手工汇率
- 不支持隐式乘法，`2x` 不会被解释成 `2*x`

## 一元方程

等号两边出现同一个未知量时，会当作一元方程求解（移项后用多项式求解，系数为精确有理数）：

| 输入 | 按回车后 |
| --- | --- |
| `x+3=5=` | `x+3=5=2` |
| `a+3=5;a=` | `a+3=5;a=2` |
| `2*x=10=` | `2*x=10=5` |
| `2*x+3=7=` | `2*x+3=7=2` |
| `x/2=3=` | `x/2=3=6` |
| `x^2=4=` | `x^2=4=-2 或 2` |
| `x^2+1=0=` | `x^2+1=0=1i 或 -1i`（共轭复根） |
| `x^3=2=` | `x^3=2=1.25992105`（数值解） |

- **一次方程**：移项直接得到精确解
- **二次方程**：求根公式；判别式为负时给出共轭复根
- **三次及以上**：牛顿迭代求一个实根
- 乘法必须显式写 `*`：`2*x`、`2*(x+1)`、`(x+1)*(x-1)`；不再支持隐含乘法
- 行内赋值可以与方程混用：`n=2;n*x=6=` → `n=2;n*x=6=3`
- 方程无解时会提示（例如 `3=5`）

## 结果精度

设置里可以指定结果的显示精度：

- **精确**（默认）：能除尽就原样显示，例如 `12*5=` → `60`、`1/8=` → `0.125`；除不尽时保留内置的 40 位
- **保留小数位数**：按指定位数四舍五入，末尾多余的 0 会去掉
- **保留有效数字位数**：按指定有效数字四舍五入，`1234.5678` 取 2 位 → `1200`

位数范围 0–15（有效数字 1–15）。精度设置同时作用于普通算式和方程解，例如设为 2 位小数后 `3*x=1=` → `3*x=1=0.33`。

舍入是**十进制精确舍入**：`1.005` 保留 2 位小数得到 `1.01`，不会像浮点数那样得到 `1.00`。

## 支持的写法

- **四则运算**：`+` `-` `*` `/`，以及 `×` `÷` `·` 等符号
- **优先级**：按常规算式优先级（先乘除后加减），支持括号 `()`
- **幂与取模**：`2^10`、`2**8`、`7%2`
- **百分比**：`50%` = 0.5，`200*10%` = 20
- **千分位**：`1,000+1=` → `1,000+1=1001`
- **全角符号**：`１２＋３=`、`（２＋３）＊４=` 都能识别
- **常量**：`pi`（π）、`e`
- **函数**：`sqrt` `abs` `round` `floor` `ceil` `trunc` `min` `max` `sum` `avg` `log` `ln` `exp` `sin` `cos` `tan` `asin` `acos` `atan` `pow`
- **行内赋值**：`a=3;a*2=` → `a=3;a*2=6`
- **负数与复数**：`-5+3=` → `-5+3=-2`；`sqrt(-4)=` → `sqrt(-4)=2i`

## 计算精度

插件不使用 `eval` / `new Function`，而是自己实现了表达式解析和**十进制高精度运算**：

- `0.1+0.2=` 得到干净的 `0.3`（而不是 `0.30000000000000004`）
- 大整数不会丢精度：`99999999999999999999+1=` 得到完整结果
- 除不尽时保留 40 位小数，例如 `1/3=`

## 设置

插件不占用顶栏。设置入口是顶栏右侧的插件菜单：**插件图标 →「等号计算」**。

- **等号自动结算**：普通编辑器中的等号结算总开关
- **计算笔记本自动重算**：关闭后编辑只保存，使用「立即计算」手动刷新
- **时间与日期 / 时区**：分别控制日期时间函数和时区函数
- **标准及复合单位 / 自定义单位**：分别控制内置单位运算和 `unit` 声明
- **分组汇总**：控制 `prev`、`total`、`average`
- **货币换算 / 在线汇率**：分别控制货币功能和联网更新；关闭在线更新后仍可使用手工及缓存汇率
- **示例按钮**：控制右上角「示例」是否显示；各开关修改后立即刷新打开的计算块
- **空格键也触发**：默认关闭（空格是常用输入键，开启后会影响默认行为）
- **支持 Ctrl/⌘ + 回车**：默认开启，可在关闭自动结算时手动触发一次
- **结果精度**：精确 / 保留小数位数 / 保留有效数字位数
- **手工汇率**：JSON 格式，优先于在线汇率
- **节假日 / 调休工作日**：用逗号或换行分隔的 `YYYY-MM-DD` 日期
- **在线参考汇率**：手动更新并显示数据来源与日期

> 设置面板必须给 `Setting` 传 `confirmCallback`：思源内部实现里会取
> `.b3-dialog__action .b3-button` 这两个按钮，没有 `confirmCallback` 时按钮容器被隐藏、
> 取不到按钮，`btnsElement[0]` 为 `undefined` 会抛错，表现为「点设置没反应」。

## 行为说明

- 只有在**光标前**的文本以等号结尾、且等号前是完整的算式时才会结算；否则回车保持默认的换行行为。
- 结算后光标停在结果末尾，块内容会通过思源的事务接口写回，因此**支持撤销**、也会同步到内核。
- `==`、`>=`、`<=` 这类比较符不会被当成算式。
- `a=` 这类只有变量名的写法不会结算（等号后面还没有数值）。
- 代码块、表格、只读文档中的内容不会被修改。
